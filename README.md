Crie um site completo para uma academia/personal trainer, com foco em vendas de planos de treino e suplementos. O site deve ter:

Design geral:

Visual moderno, estilo fitness/academia — tons escuros (preto, cinza chumbo) combinados com uma cor de destaque vibrante (laranja ou verde neon)

Tipografia forte e impactante para títulos, fontes legíveis para o corpo

Totalmente responsivo (mobile first)

Páginas/seções:

Home

Hero section com imagem/vídeo de fundo, chamada de impacto (ex: "Transforme seu corpo, transforme sua vida") e botão CTA

Seção "Sobre" com apresentação do personal/academia

Seção de diferenciais (treino personalizado, acompanhamento, suplementação, resultados)

Depoimentos de alunos com foto, nome e resultado alcançado

Galeria de fotos de antes/depois

Treinos

Cards com categorias de treino (emagrecimento, hipertrofia, condicionamento, online, presencial)

Cada card com descrição curta, duração e botão "saiba mais"

Página de detalhe do treino com plano, objetivo e valor

Suplementos (loja)

Grid de produtos com imagem, nome, preço e botão "adicionar ao carrinho"

Filtro por categoria (whey, creatina, pré-treino, vitaminas, etc)

Página de produto individual com descrição, modo de uso e avaliações

Carrinho de compras funcional (mesmo que simulado)

Planos

Tabela comparativa de planos (mensal, trimestral, anual) com preços e benefícios de cada um

Botão de assinatura/contratação

Contato

Formulário de contato (nome, email, telefone, mensagem)

Links para redes sociais e WhatsApp

Mapa de localização (se for academia física)

Funcionalidades extras:

Menu de navegação fixo no topo com scroll suave entre seções

Botão flutuante de WhatsApp

Animações leves ao rolar a página (fade in / slide up)

Área de login para alunos (opcional, pode ser mockada)

Use dados fictícios realistas para preencher o conteúdo (nomes, preços, depoimentos) até que eu substitua pelas informações reais.
